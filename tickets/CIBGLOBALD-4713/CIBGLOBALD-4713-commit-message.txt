CIBGLOBALD-4713 - Profitability modal shows the Profitability renderer and adds Download PDF

- dmt_passport_modal: in Profitability mode the body is the new LWC dmt_profitability_view. Footer buttons are built from a list: Close plus Download PDF (brand, download icon), disabled while loading, without profitability data or during a download.
- dmt_profitability_view (new): shows the HTML of DMT_OppProfitabilityRenderer, the same renderer used by the NBC views, so the screen and the PDF come from one implementation. The chart image is generated in the browser with dmt_profitability_chart and sent to Apex. Screen-only sizing and horizontal scroll per table. The External RWA calculate button is inserted at the marker left by the renderer. The PDF is generated on demand with DMT_PdfService from the HTML on screen, without the button and with links as plain text. Message when the Opportunity has no profitability data.
- DMT_Profitability_utils: without sharing. New renderProfitabilityHtml builds only the wrapper fields the renderer reads (Opportunity from DMT_View_Selector.getOpportunityWithRelatedData, saved Passport features from DMT_ViewController.getFeatures) and calls DMT_RendererFactory, with the optional External RWA callout (DMTO_ExternalOrchestrators) before rendering. New preloadProfitabilityData shared with DMT_ViewController.
- DMT_ViewController: LineDataWrapper fields for the External RWA values, the RWA link info and the modal marker flag. The profitability preload moves to DMT_Profitability_utils.preloadProfitabilityData.
- DMT_OppProfitabilityRenderer: uses the chart image sent by the browser, data-dmt-table-block hooks on the three tables, External RWA 1Y column with the link to the RWA calculator when values are passed, and the empty marker for the modal button only when the modal asks for it.
- DMT_Test_DataFactory: new generatePassport.
- DMT_Profitability_utilsTest and DMT_ProfitabilityRendererTest: tests for the new method, the RWA column, the marker and the chart image; System.assert calls replaced by the Assert class.
