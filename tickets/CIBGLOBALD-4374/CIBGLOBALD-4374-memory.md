# CIBGLOBALD-4374 - SOQL optimization: manual Risk request and Draft -> Proposal

Branch (BBVA): feature/CIBGLOBALD-4374-dmt-optimizacion-soql-request-manual-de-risk-y-draft-proposal. Personal repo branch: 4374. Ticket created 2026-09-22; several tickets have since touched this logic (4117 restart framework, 4477 bulkified auto-start, 4617), so parts may already be optimized.

## Requirement (summary)
1. Manual 'Request' of Risk on an Opportunity (done from LWC dmt_passport / dmt_passport_opportunity; creates Cases and Tasks). Used as fallback when the automatic Request at end of Business did not fire. SOQL consumption grows with number of holders/clients in Multiholder opps and reached 101. Bulkify; if not enough, split into async transactions without changing functional logic or breaking Approval.
2. Draft -> Proposal with many open Cases/Tasks: logic that checks whether Tasks/Cases must be cancelled/regenerated hit 101 queries. Was refactored; verify it no longer scales with number of Cases.
3. Measure SOQL before/after with high-volume cases (Multiholder, many Cases/Tasks, manual Risk request, Draft->Proposal with task regeneration).
Constraint: exactly the same Cases/Tasks generated/cancelled/relaunched.
