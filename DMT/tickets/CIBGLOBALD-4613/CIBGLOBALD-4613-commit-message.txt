CIBGLOBALD-4613 - General Validations: tenor check only for One-Off products, MX restriction amount and per-table maturity, passport payload query reduction

- DMT_OppFeatureGenCons_Calc: the 'Tenors Payment Date' validation is calculated only on One-Off products (OpportunityLineItem.DMT_Line_Oneoffdeal__c other than 'Line'). An Opportunity with Line products only no longer gets it; a mixed Opportunity considers only its One-Off products. New userDefinedTenorsValidation and isLineProduct.
- DMT_LineFeatureGenCons_Calc: new validation 'Line amount informed for restricted products' (restrictionWithoutAmount) for the MX template: YELLOW when a product enabled in the Derivatives, Depos or Repos restriction table has no amount in its line table. Only geographies whose DMT_OperationalRestrictionsTRSR__mdt records carry the layout2 flags (MX) get it.
- DMT_LineFeatureGenCons_Calc: restricGreaterTerm compares each product maturity with the End Term of its own table (Derivatives, Depos or Repos from the layout2 flags) instead of always the Derivatives table.
- Custom labels dmt_cl_FeatureRestrictionAmountTitle, dmt_cl_FeatureRestrictionAmountGreen, dmt_cl_FeatureRestrictionAmountYellow.
- Enhancement to existing process (passport payload, DMT_Passport_Helper.buildStandardLinePayload and buildOtherProductsPayload): transaction caches in DMT_Passport_Selector for DMT_Risk_Line_Term__c (getRiskLineTerm, getRiskLineTermWhithoutRiskType) and DMT_Line_Product_Item__c (getProductLineItems), with line and parent line loaded in one query; the payload line is passed to calculateFeatureGenCons, checkValidations (new DMT_Line__c overload), isCurrentLine and validationRenovationOtherLines (new overload, no getLine inside the loop; getLine now selects DMT_Parent_Line__r.Amount__c). SOQL per payload: Treasury line with parent 31 -> 24 (line 3 -> 1, product items 3 -> 1, risk terms 4 -> 1); OtherProducts line with parent 24 -> 19 (line 4 -> 1, risk terms 3 -> 1; the old loop added 2 more per extra risk term); Treasury line without parent 2 fewer.
- Enhancement fix to existing process: DMT_Passport_Helper.parentConsumsStandard read the parent Derivatives terms with the external Id Line_Id__c, which never matches DMT_Risk_Line_Term__c.DMT_Line__c, so they were never found. It now uses DMT_Parent_Line__c: endDateParent of productParent 03 = parent Start Date + longest parent Derivatives End Term (before: always the parent Start Date).
- Tests: new cases in DMT_LineFeatureGenCons_Calc_test, DMT_OppFeatureGenCons_Calc_Test and DMT_Passport_Helper_test; Assert class in the touched test files; testCheckValidationsAllConditions client data aligned with the factory client.
