CIBGLOBALD-4711 - PRO - PRE-DEPLOYMENT
URL host copied from custom setting DMTO_Endpoint_PRO (https://aso-backend-global.live-01.platform.bbva.com/dmto/v0/).

1. Developer Console > Debug > Open Execute Anonymous Window.
2. Paste the script below.
3. Click Execute.
4. Check the log shows: DONE DMT_ProfitabilityDownloadDetail_PRO

iaso__GBL_Rest_Services_Url__c endpoint = new iaso__GBL_Rest_Services_Url__c(Name = 'DMT_ProfitabilityDownloadDetail_PRO');
for (iaso__GBL_Rest_Services_Url__c existing : [SELECT Id FROM iaso__GBL_Rest_Services_Url__c WHERE Name = :endpoint.Name LIMIT 1]) {
    endpoint.Id = existing.Id;
}
endpoint.iaso__Url__c = 'https://aso-backend-global.live-01.platform.bbva.com/dmt/v0/';
endpoint.iaso__Enable_Log__c = true;
upsert endpoint;
System.debug('DONE ' + endpoint.Name);
