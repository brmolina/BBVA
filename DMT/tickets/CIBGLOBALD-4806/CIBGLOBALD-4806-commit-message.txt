CIBGLOBALD-4806 - Client Type from the HPG Rating Tool, Client Data compared against the Main Holder, same-group clone keeps its own association

- DMT_CreateOpportunityService: new resolveClientTypeFromHpg reads the HPG Rating Tool (ratingSystemId, backend gf_rating_system_id) and validates it against catalog D971 ('Fin Inst B' / 'Fin Inst I' mapped to 'Fin Inst-B' / 'Fin Inst-I'). buildOpportunityClient sets Counterpart__c (Client Type) from it and keeps the Account Segment label only when HPG has no valid value. Used by new Opportunities and by every clone path that rebuilds the client data.
- DMT_OpportunityClientController: Group flows resolve the Main Holder Account (Account.g_customer_id__c = Custom_Association_Opportunity__c.g_customer_id__c) instead of Opportunity.AccountId (the Group) to load and compare HPG data. The original Client Type follows the same HPG rule, with the Main Holder Segment as fallback, also when a new Main Holder is picked.
- DMT_OpportunityCloneUtil: the same-group clone inserts the cloned DMT_Opportunity_Client__c after the clone's own Custom_Association_Opportunity__c and links it to it. It kept the source Opportunity association, so Client Data showed no Main Holder on the clone.
- Tests: DMT_CreateOpportunityServiceTest adds testBuildOpportunityClient_ClientTypeFromHpg; DMT_OpportunityCloneUtilTest checks the association of the cloned client.
